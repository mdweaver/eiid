## 1. Setting

### 1.1 Units, groups, outcomes and elections

* **Units** $i=1,\dots,p$ (precincts, townships), with $N_i>0$ people.
* **Groups** (rows) $r=1,\dots,R$: a fixed characteristic of each person (veteran or not; a party registration recorded once; a census category).
* **Outcomes** (columns) $c=1,\dots,C$ on a **common base** (for example yes, no, abstain among the eligible). A share among voters is a ratio target, handled by Charnes–Cooper as in 2d C1.
* **Elections** $t\in\mathcal T=\{-L,\dots,-1,0,1,\dots,P\}$ in event time, $T=L+1+P\ge2$ (decision D11).
  * Election $0$ is the **base**: the last election before treatment.
  * Elections $t<0$ are earlier **pre-periods** ($L\ge0$; relative-magnitude and smoothness bounds need $L\ge1$).
  * Elections $t\ge1$ are **post-periods**.

### 1.2 The fixed population (the base case)

**(FP)** The same $N_i$ people live in unit $i$ at every election, and each keeps the same group. So the group counts $a_{ir}$ ($\sum_ra_{ir}=N_i$) are the same in every period, while the outcome counts $b_{ict}$ ($\sum_cb_{ict}=N_i$) vary.

Every departure from (FP) (entry, exit, aging-in, interval bases, changing boundaries, changing group membership) is an item of the gap register (§8), not a result of this note.

**Unknowns.** The realised counts $n_{irct}\ge0$ with $\sum_cn_{irct}=a_{ir}$ and $\sum_rn_{irct}=b_{ict}$. Write $\mathcal P_{it}$ for unit $i$'s transportation polytope at election $t$ (6a §1.1), $\mathcal P^{\mathcal T}:=\prod_t\prod_i\mathcal P_{it}$, and $n=(n_{irct})$. Rates: $\beta_{irct}=n_{irct}/a_{ir}$ for $a_{ir}>0$.

**Lemma E1 (stacking).** Under (FP), $\mathcal P^{\mathcal T}$ is the count-layer polytope of 6a §1.1 for the unit set $\{(i,t)\}$, with row margins $a_{ir}$ (the same for every $t$) and column margins $b_{ict}$. Hence 6a R19(a) and R19(d) apply verbatim to every linear target and every finite set of linear rows on $n$, **including rows that couple periods**: the set of target values is $\varphi(F)$, an interval when $F\ne\emptyset$, valid, and sharp for continuous tables given the margins and rows; CR-type unions give unions of intervals.

*Proof.*
1. Election $t$'s margins constrain only $n_{\cdot\cdot\cdot t}$; (FP) makes the row margins of every $(i,t)$ equal to $a_{ir}$. [Def; FP]
2. So the feasible set is the product of the unit-period transportation polytopes, which is 6a's $\mathcal P$ for the unit set $\{(i,t)\}$. [1; 6a §1.1]
3. 6a R19(a) items 1–4 and R19(d) use only that $\mathcal P$ is a product of transportation polytopes and that the rows are linear. [6a:R19(a),(d)] ∎

*Check.* E1 (Minkowski sums over periods; 40 designs, R = C = 3, T = 3). **Status: P; proof reviewed (docs/extension/reviews/PHASE2e_proof_review.md).**

**Lemma E2 (within-person tables add nothing for period-margin targets).** Let $\nu_{irc_{-L}\dots c_P}\ge0$ be the panel table (people in unit $i$, group $r$, with outcome sequence $(c_t)_t$). Every family of period tables $n\in\mathcal P^{\mathcal T}$ is the set of one-period marginals of some panel table, and of an **integer** panel table when $n$ is integer. Hence, for targets and rows that depend on the panel only through the period tables (all targets of this note), the sets are the same whether the unknown is $\nu$ or $n$. Transition targets ("share of group $r$ that switched to $c$") are not of this kind and need $\nu$.

*Proof.*
1. Real case: $\nu_{irc_{-L}\dots c_P}:=a_{ir}\prod_t(n_{irc_tt}/a_{ir})$ for $a_{ir}>0$ (independent coupling given $(i,r)$) has the period tables as marginals. [coupling]
2. Integer case: list the $a_{ir}$ people of $(i,r)$; at each election give the first $n_{ir1t}$ of them outcome 1, the next $n_{ir2t}$ outcome 2, and so on (in any order per election). Counting outcome sequences gives an integer $\nu$ with the right marginals. [Def; alg]
3. A target or row that depends on $\nu$ only through its marginals takes the same values on $\{\nu\}$ and on $\mathcal P^{\mathcal T}$. [1–2] ∎

*Check.* E2 (200 integer instances, T = 3). Generalises 1b B2 Δ8 (two periods, a sketch there). **Status: P; proof reviewed (docs/extension/reviews/PHASE2e_proof_review.md).**

### 1.3 Targets

For a unit set $\mathcal S$ (default: all units), with $Y_{rct}(\mathcal S)=\sum_{i\in\mathcal S}n_{irct}$ and $A_r(\mathcal S)=\sum_{i\in\mathcal S}a_{ir}$:
* **group rates** $B_{rct}(\mathcal S)=Y_{rct}(\mathcal S)/A_r(\mathcal S)$ (P3 §0.2's actual rate);
* **gaps** $g_{rs,ct}=B_{rct}-B_{sct}$; one-vs-rest gaps $g_{r\neg r,ct}$ with $B_{\neg r,ct}=(Y_{ct}-Y_{rct})/(N-A_r)$;
* **DiDs** $D_c(r,s;u,t)=g_{rs,ct}-g_{rs,cu}$; the **event-study vector** $D_t:=g_{rs,ct}-g_{rs,c0}$ ($t\ne0$), relative to the base; **consecutive DiDs** $g_{rs,ct}-g_{rs,c,t-1}$.

All are linear count targets with coefficients that are functions of the design ($1/A_r(\mathcal S)$), as 6a Lemma 4.1 and R27 require. The **model-implied** versions $\tilde B$, $\tilde D$ replace $\beta_{irct}$ by $m_{rct}(V_i)=E[\beta_{irct}\mid V_i]$ (P3 §0.2; 2d §0.1). Under (FP) each person's **individual change** $\Delta Y_j(u,t)=\mathbf 1\{Y_{jt}=c\}-\mathbf 1\{Y_{ju}=c\}\in\{-1,0,1\}$ is defined, and $\Delta\beta_{irc}(u,t)=\beta_{irct}-\beta_{ircu}$ is the mean of the individual changes of group $r$ in unit $i$.

### 1.4 What is descriptive and what is causal

* A **descriptive** statement is about the realised tables of the actual groups (count layer) or about the model-implied rates of the actual groups (model layer): "veterans' support rose 5 to 25 points more than others'".
* A **causal** statement is about potential outcomes (§5): "service raised veterans' support by …". It is always **on top of** (↑) a descriptive set, never mixed into it.
* **Rule (Definition 5.1 below).** A causal label requires a stated population, a stated treated group (and a comparison group when the trend assumption uses one), a stated trend assumption, a stated spillover assumption and no anticipation. Without a trend assumption the descriptive DiD says nothing causal (Prop. E15).

## 2. Descriptive rungs, count layer (exact)

### 2.1 Δ0 for T elections

**Proposition E3 (Δ0: no link between elections).** Margins only, (FP).
(a) For a target that is a sum of per-election targets, $\varphi(n)=\sum_t\varphi_t(n_{\cdot\cdot\cdot t})$, the set of values is the Minkowski sum $\sum_t\varphi_t(\mathcal P_t)$, every value attained (continuous tables).
(b) For a two-row, or one-vs-rest, one-column DiD, the set is $[G^-_t-G^+_u,\ G^+_t-G^-_u]$, where $[G^-_t,G^+_t]$ is election $t$'s exact gap range: $[B^L_{rct}-B^U_{sct},\ B^U_{rct}-B^L_{sct}]$ with cellwise Duncan–Davis ends for a named pair (6a Lemma 2.1(b): both ends are attained jointly), and the gap evaluated at $Y_{rct}=Y^L_{rct},Y^U_{rct}$ for one-vs-rest (the gap is increasing in $Y_{rct}$). This holds for any $R$, $C$ and $T$.
(c) **The joint set of the event-study vector is not the box of the separate ranges.** For a named pair and one column, the joint set of $(D_t)_{t\ne0}$ is $\{(g_t-g_0)_{t\ne0}:\ g_t\in[G^-_t,G^+_t]\ \forall t\}$, the image of a box under a linear map. Whenever $T\ge3$ (two non-base elections) and $[G^-_0,G^+_0]$ has positive length, whatever the other elections' ranges, some corner of the box of separate ranges is infeasible (for example $D_1$ at its maximum, which needs $g_0=G^-_0$, with $D_{-1}$ at its minimum, which needs $g_0=G^+_0$). For **consecutive** DiDs the relevant condition is that a **shared interior** election (one in two consecutive pairs) has a gap range of positive length: with elections 0, 1, 2 and only election 0 uncertain, the consecutive-difference set is its coordinate box, while the base-relative vector with base 0 is not (check E3 [V], finding 12).
(d) **Per-period LCE.** Under per-period LCE (M2 with elections as groups) the sharp identified set of $(K_t)_{t\in\mathcal T}$ is $\prod_t\Theta_{I,t}$, each factor computed from its own election's law; the outer set is $\prod_t\Theta_{O,t}$.

*Proof.*
1. (a): $\mathcal P^{\mathcal T}$ is a product over elections [E1], and $\varphi$ is a sum of functions of the factors. [sep] Each factor's range is an interval with all values attained [6a:R19(a)], so the sum's range is the Minkowski sum, all values attained. [conn]
2. (b): $D=g_t-g_u$ is of the form (a). Election $t$'s gap range is exact by 6a Lemma 2.1(b) (named pair; the separate optima are attained by one table) or by monotonicity in $Y_{rct}$ (one-vs-rest, $B_{\neg r}$ decreasing in $Y_{rct}$) together with 6a Lemma 2.1(a). [6a:L2.1; 1]
3. (c): $(g_t)_t$ ranges over the box $\prod_t[G^-_t,G^+_t]$ [1–2], and $(D_t)$ is its image under $g\mapsto(g_t-g_0)_{t\ne0}$. [Def] At the named corner $D_1=G^+_1-G^-_0$ forces $g_0=G^-_0$ and $D_{-1}=G^-_{-1}-G^+_0$ forces $g_0=G^+_0$, incompatible when $G^-_0<G^+_0$. [alg]
4. (d): 2d Δ0(b)'s proof with the $T$-fold product $\mathcal S(w)=\prod_tS(x,t_t)$ in place of the twofold one: Lemma G (2d §1) applies because products preserve its hypotheses; the support function of a product is the sum [prod-supp]; setting all but one $u_t$ to 0 gives each election's condition, and summing gives the joint one. [2d:L G; 2d:Δ0(b)] ∎

*Checks.* E1 [V] (a), (b) (40 designs, R = C = 3, T = 3); **E1 [F]** (c) (the box corner infeasible in all 40 designs). [P2d] Δ0's own checks run unchanged. **Status: P; proof reviewed (docs/extension/reviews/PHASE2e_proof_review.md)**; the consecutive-DiD sentence of (c): P; proof review pending. (a)–(b) generalise 2d Δ0(a) to R×C and T elections; (d) generalises 2d Δ0(b).

### 2.2 Rows on changes

**Lemma E4 (rows on changes are rows on the product).** (FP). Fix a column $c$, elections $u<t$, a unit set $\mathcal S$ with $\operatorname{Var}_p(X_r)>0$ over $\mathcal S$ (weights $p_i=N_i/N(\mathcal S)$), and write $\Delta$ for "election $t$ minus election $u$".
(a) $\Delta T_{ic}=\sum_rX_{ir}\,\Delta\beta_{irc}$, and the realised associations of 2c Def. 1 computed on $\Delta\beta$ (pairwise $\delta^\Delta_B(r,s)$, one-vs-rest $\delta^{\Delta,r}_B$, W2 $\Delta^\Delta$, W1 $\delta^{\Delta,r}_W$) are affine functions of the two-election table with design coefficients; each equals election $t$'s association minus election $u$'s.
(b) **One-vs-rest rows depend on one number.** $\delta^{\Delta,r}_B(\mathcal S)$, $\delta^{\Delta,r}_W(\mathcal S)$ and the one-vs-rest DiD $D^r_c(u,t;\mathcal S)$ are affine in the single aggregate
$$Z:=Y_{rct}(\mathcal S)-Y_{rcu}(\mathcal S),$$
with slopes $1/N(\mathcal S)$, $-\operatorname{Var}_p(X_r)\kappa_r$ and $\kappa_r:=1/A_r(\mathcal S)+1/(N(\mathcal S)-A_r(\mathcal S))$ respectively, and intercepts that depend on both elections' outcome margins.
(c) **Identities on changes.** With $ER^r_\Delta:=\operatorname{Cov}_p(\Delta T_c,X_r)/\operatorname{Var}_p(X_r)$ and $NM^r_\Delta:=\operatorname{Cov}_p(\Delta T_c,X_r)/(\mu_r(1-\mu_r))$ (the collapsed neighbourhood-model difference $NM_r-NM_{\neg r}$ computed on $\Delta T$),
$$ER^r_\Delta-D^r_c=\frac{\delta^{\Delta,r}_W}{\operatorname{Var}_p(X_r)},\qquad NM^r_\Delta-D^r_c=-\frac{\delta^{\Delta,r}_B}{\mu_r(1-\mu_r)},\qquad NM^r_\Delta=\gamma_r\,ER^r_\Delta,$$
with $\gamma_r=\operatorname{Var}_p(X_r)/(\mu_r(1-\mu_r))\in(0,1]$.

*Proof.*
1. (a): A1 holds in both elections with the same $X_i$ [FP], so $\Delta T_{ic}=\sum_rX_{ir}\Delta\beta_{irc}$. 2c Lemma M1(d) shows the associations are affine in the unit rates with design coefficients, for any bounded rates; apply it to each election and subtract. $\beta_{irct}=n_{irct}/a_{ir}$ is linear in $n$. [A1; 2c:M1(d); lin]
2. (b): $\delta^r_B=\sum_{s\ne r}E_p[X_rX_s(\beta_r-\beta_s)]=E_p[X_r(\beta_r-T_c)]$, using $\sum_{s\ne r}X_s\beta_s=T_c-X_r\beta_r$; in counts this is $(Y_{rc}(\mathcal S)-\sum_{i\in\mathcal S}X_{ir}b_{ic})/N(\mathcal S)$. [Def; simplex] $D^r$ is $\kappa_rY_{rc}-Y_c/(N-A_r)$ per election. $\delta^r_W=\operatorname{Var}_p(X_r)(ER^r-D^r)$ by 2c Lemma M1(c), with $ER^r$ a function of the data only. Subtract the two elections. [2c:M1(c); alg]
3. (c): the collapsed population $(X_r,\Delta\beta_r,\Delta\beta^{\neg r})$, with $\Delta\beta^{\neg r}_i=\sum_{s\ne r}X_{is}\Delta\beta_{is}/(1-X_{ir})\in[-1,1]$, is a two-group population for the bounded outcome $\Delta Y$ in EGGHM's sense (2c M1(c) proof steps 1–5 with $\Delta$; only A1 and boundedness are used). Apply [EGGHM:P4, P6]. For the last identity: $E_p[X_r\Delta T]/\mu_r-E_p[(1-X_r)\Delta T]/(1-\mu_r)=\operatorname{Cov}_p(X_r,\Delta T)/(\mu_r(1-\mu_r))$. [2c:M1(c); EGGHM:P4, P6; alg] ∎

*Check.* E4 (60 designs, R = C = 3: the identities from the definitions of 2c Def. 1 on random latent tables, error < $10^{-10}$). **Status: P; proof reviewed (docs/extension/reviews/PHASE2e_proof_review.md).** Generalises 2d Δ4(a) (2×2) and the one-vs-rest part of 6a Lemma C1 to changes. A unit with zero weight can be omitted.

### 2.3 Δ4 beyond 2×2

**Proposition E5 (sign rows and CR on changes, R×C, T elections).** (FP), continuous tables, margins only unless rows are named. Fix $(r,c,u,t,\mathcal S)$ with $\operatorname{Var}_p(X_r)>0$; let $[Z^-,Z^+]=[Y^L_{rct}(\mathcal S)-Y^U_{rcu}(\mathcal S),\ Y^U_{rct}(\mathcal S)-Y^L_{rcu}(\mathcal S)]$ (Duncan–Davis extremes of each election's aggregate, 6a Lemma 2.1(a)) and $D^\pm=D^r_c(Z^\pm)$.
(a) The set of $D^r_c(u,t;\mathcal S)$ is $[D^-,D^+]$, every value attained.
(b) **W1 signs on changes.** $\delta^{\Delta,r}_W\ge0$ gives $[D^-,\min\{D^+,ER^r_\Delta\}]$, empty iff $ER^r_\Delta<D^-$; $\delta^{\Delta,r}_W\le0$ gives $[\max\{D^-,ER^r_\Delta\},D^+]$, empty iff $ER^r_\Delta>D^+$; $\delta^{\Delta,r}_B\ge0$ gives $[\max\{D^-,NM^r_\Delta\},D^+]$; $\delta^{\Delta,r}_B\le0$ gives $[D^-,\min\{D^+,NM^r_\Delta\}]$.
(c) $NM^r_\Delta\in[D^-,D^+]$ always, so between signs on changes are never refuted in this problem.
(d) **CR on changes** ($\delta^{\Delta,r}_W\,\delta^{\Delta,r}_B\ge0$): the set is $[NM^r_\Delta,\min\{D^+,ER^r_\Delta\}]$ if $ER^r_\Delta\ge0$ and $[\max\{D^-,ER^r_\Delta\},NM^r_\Delta]$ if $ER^r_\Delta<0$. It is never empty, and if $\gamma_r<1$ and $ER^r_\Delta\ne0$ exactly one branch is non-empty and $\operatorname{sign}D^r_c=\operatorname{sign}ER^r_\Delta$.
(e) **Other rows.** Pairwise $\delta^\Delta_B(r,s)$, W2, signs in several columns, several unit sets, unit-level orderings of changes ($\Delta\beta_{irc}\ge\Delta\beta_{isc}$, a two-election row in unit $i$), known cells and published totals in any election, and within-election rows: the set is the LP of Lemma E1 (sharp for continuous tables); CR is a union of two LPs.
(f) **Several period pairs.** Rows for pairs $(u_k,t_k)$, $k=1,\dots,K$, are rows on the same product: one LP; CR in each of $K$ pairs is a union of at most $2^K$ branch LPs, and the set is the union of their intervals.

*Proof.*
1. (a): $Z=Y_{rct}(\mathcal S)-Y_{rcu}(\mathcal S)$, the two terms in different factors of the product [E1], each taking every value in its Duncan–Davis interval [6a:L2.1(a)], so $Z$ takes every value in $[Z^-,Z^+]$. [sep; conn] $D^r_c$ is affine increasing in $Z$. [E4(b)]
2. (b): by E4(c), with $\operatorname{Var}_p(X_r)>0$: $\delta^{\Delta,r}_W\ge0\iff D^r_c\le ER^r_\Delta$ and $\delta^{\Delta,r}_B\ge0\iff D^r_c\ge NM^r_\Delta$. Intersect with (a). [E4(c); conn]
3. (c): put $\beta_{isct'}=T_{ict'}$ for every row $s$ and both elections $t'\in\{u,t\}$. This lies in each $S(X_i,T_{it'})$; then $\Delta\beta_{is}=\Delta T_i$ for every $s$, so $\delta^{\Delta,r}_B=E_p[X_r(\Delta\beta_r-\Delta T)]=0$ and $D^r_c=NM^r_\Delta$ by E4(c). [Def S; E4]
4. (d): $NM^r_\Delta=\gamma_rER^r_\Delta$ with $\gamma_r\in(0,1]$ [E4(c); 2c:M3 step 5]. If $ER^r_\Delta\ge0$ then $NM^r_\Delta\le ER^r_\Delta$ and the positive branch is $[NM^r_\Delta,\min\{D^+,ER^r_\Delta\}]$, non-empty since $D^-\le NM^r_\Delta\le D^+$ [3]. The negative branch needs $ER^r_\Delta\le D\le NM^r_\Delta=\gamma_rER^r_\Delta$, which for $ER^r_\Delta>0$ forces $\gamma_r=1$. The case $ER^r_\Delta<0$ is symmetric; on the non-empty branch $D$ has the sign of $ER^r_\Delta$. [2c:M3 steps 6–8 with $Z$]
5. (e), (f): every row named is affine in $n$ [E4(a); Def]; apply E1 [stack; 6a:R19(a) item 4 for unions]. ∎

### 2.4 Finite contrasts on changes (the count-layer form of DiD-S)

**Proposition E6 (contrast on changes, two bins).** (FP), $R=2$ (rows 1, 2), a column $c$, elections $u<t$, and two prespecified disjoint unit sets ("bins") $\mathcal L,\mathcal H$ with both groups present in each bin ($A_1(b),A_2(b)>0$), pooled compositions $\bar x_b=A_1(b)/N(b)$ and $\lambda:=\bar x_{\mathcal H}-\bar x_{\mathcal L}>0$. Write $\Delta m_{r,b}=\Delta Y_{rc}(b)/A_r(b)$ (bin change rates), $\Delta\tau_b=\Delta Y_c(b)/N(b)$ (observed), and the **bin-averaged DiD** $\bar D:=\tfrac12\sum_{b\in\{\mathcal L,\mathcal H\}}(\Delta m_{1,b}-\Delta m_{2,b})$.
(a) **Identity** (Kitagawa on changes): $\Delta\tau_{\mathcal H}-\Delta\tau_{\mathcal L}=\lambda\bar D+\rho$, with the "rate" term $\rho:=\bar{\bar x}(\Delta m_{1,\mathcal H}-\Delta m_{1,\mathcal L})+(1-\bar{\bar x})(\Delta m_{2,\mathcal H}-\Delta m_{2,\mathcal L})$, $\bar{\bar x}=(\bar x_{\mathcal H}+\bar x_{\mathcal L})/2$.
(b) The two beliefs "mix $\ge0$" ($\lambda\bar D\ge0$) and "rate $\ge0$" ($\rho\ge0$) are linear count rows, and together they are equivalent to $\bar D\in[0,(\Delta\tau_{\mathcal H}-\Delta\tau_{\mathcal L})/\lambda]$. The set is
$$\big[\max\{0,\bar D^-\},\ \min\{\bar D^+,(\Delta\tau_{\mathcal H}-\Delta\tau_{\mathcal L})/\lambda\}\big],$$
with $[\bar D^-,\bar D^+]$ the margins-only range of $\bar D$; it is empty iff $\max\{0,\bar D^-\}>\min\{\bar D^+,\mathrm{cap}\}$, i.e. iff $\Delta\tau_{\mathcal H}<\Delta\tau_{\mathcal L}$ (the two beliefs are jointly refuted), or $\bar D^+<0$ (the mix belief is refuted by the margins), or the cap is below $\bar D^-$ (the rate belief is refuted). Here $\mathrm{cap}:=(\Delta\tau_{\mathcal H}-\Delta\tau_{\mathcal L})/\lambda$. Sharp for continuous tables.
(c) The rate belief alone gives $\bar D\le(\Delta\tau_{\mathcal H}-\Delta\tau_{\mathcal L})/\lambda$ and does **not** presuppose the sign of the DiD; the mix belief alone is a sign on the bin-averaged DiD itself.

*Proof.*
1. (a): $\Delta\tau_b=\bar x_b\Delta m_{1,b}+(1-\bar x_b)\Delta m_{2,b}$ (A1 in both elections, (FP), aggregated over the bin). Apply $a_{\mathcal H}v_{\mathcal H}-a_{\mathcal L}v_{\mathcal L}=(a_{\mathcal H}-a_{\mathcal L})\frac{v_{\mathcal H}+v_{\mathcal L}}2+\frac{a_{\mathcal H}+a_{\mathcal L}}2(v_{\mathcal H}-v_{\mathcal L})$ to $(\bar x,\Delta m_1)$ and $(1-\bar x,\Delta m_2)$ and add; the first terms give $\lambda\bar D$. [A1; FP; alg]
2. (b): $\Delta\tau_b$ is observed, so $\rho=\Delta\tau_{\mathcal H}-\Delta\tau_{\mathcal L}-\lambda\bar D$ and both rows are rows on $\bar D$ alone. [1] $\bar D$ is affine with positive coefficients in $(\Delta Y_{1c}(\mathcal H),\Delta Y_{1c}(\mathcal L))$ (using $\Delta Y_{2c}(b)=\Delta Y_c(b)-\Delta Y_{1c}(b)$), whose margins-only joint range is a product of intervals with all values attained [E1; 6a:L2.1(a); sep]. So $\bar D$'s range is an interval with all values attained; intersect. [conn]
3. (c): (b) with one row. ∎

*Checks.* **E5/E6/E26 [V]** brute force (integer 2×2 tables, the identity exact, the integer set as stated); **E6 [V]** LP = closed form in 2×3 (59 designs; empty in 32, where the joint test rejects). **Status: P; proof reviewed (docs/extension/reviews/PHASE2e_proof_review.md).**  The added hypothesis (both groups in each bin): P; proof review pending. This is the count-layer version of NS §3.3's contrast "on changes" and of PD §7's DiD-S; it needs no linearity in either election. With $R\ge3$ only named pairs should be used (NS §3.3).

## 3. Descriptive rungs, model layer

The model layer targets the **model-implied** DiD $\tilde D$; the actual DiD is reached through the residual allowance (Lemma E12) and the combination rule (§4). Model **FD** (2d §3): (S1) in each election, and
$$E[\Delta\beta\mid V]=M_{\Delta H}(X)\quad\text{a.s.},\qquad \textstyle\sum_c\Delta H_c=0,$$
for one pair of elections (or several pairs, imposed jointly as in Prop. E8(e)); **levels are unrestricted**. Write $\Delta H_c=\Delta Q_c+\Delta K_c$ (symmetric plus antisymmetric part).

### 3.1 FD in R×C

**Lemma E7 (FD in R×C).** Assume FD, (FP), and A5 for the design (2a).
(a) $E[\Delta T_c\mid X]=X^\top\Delta Q_cX$; so $\Delta Q_c$ is identified and $\Delta K_c$ is not restricted by this regression.
(b) For a pair $(r,s)$ (or $r$ against the rest) and column $c$, $\tilde D_c=I_c+\ell_c(\Delta K_c)$, where $I_c$ is identified and $\ell_c$ is linear with design coefficients and involves only column $c$'s $\Delta K_c$.
(c) For $R=2$: $\ell_c=s\,\Delta\kappa_c$ with $s=\mu_{vn}(1/\mu_v+1/\mu_n)>0$ (2d Lemma FD1(b)).
(d) A pair DiD loads on $\sum_iw_{ir}(\Delta K_cX_i)_r-\sum_iw_{is}(\Delta K_cX_i)_s$ (the $\ell_c$ of (b)), **not** on the common-composition contrast $[(e_r-e_s)^\top\Delta K_c]x$: own-group weights matter, and the loading can be non-zero when every common-composition contrast for the pair vanishes (check E7 [F]: loading .0075). PD Prop. P-R's directional conclusion concerns pair restrictions **across compositions**. If the compositions used span $\mathbb R^R$ (full-dimensional support), the edge contrasts of $\Delta K_cx$ on any connected spanning tree of groups determine $\Delta K_c$, so two-sided bounds on them at a spanning set of compositions bound every coordinate; whether that narrows a given target depends on the data.

*Proof.*
1. (a): $\Delta T_c=\sum_rX_r\Delta\beta_{rc}$ [A1 both elections; FP], so $E[\Delta T_c\mid X]=X^\top\Delta H_cX=X^\top\Delta Q_cX$, since antisymmetric parts vanish in quadratic forms. $\Delta Q_c$ is unique under A5. [CE-pull; 2a:L1]
2. (b): $\tilde D_c=\sum_iw_{ir}(\Delta H_cX_i)_r-\sum_iw_{is}(\Delta H_cX_i)_s$ with sample weights; substitute $\Delta H_c=\Delta Q_c+\Delta K_c$. [2a:L2; P3 §0.2; lin]
3. (c): 2d FD1(b).
4. (d): the loading is (b)'s $\ell_c$. Tree rank: suppose $(e_r-e_s)^\top Kx=0$ for every edge $(r,s)$ of a connected spanning tree and every $x$ in a set spanning $\mathbb R^R$. Then $K_{r\cdot}=K_{s\cdot}$ on each edge, so by connectivity every row equals a common row $k$; antisymmetry gives $k_j=K_{jj}=0$ for every $j$, so $K=0$. The map from antisymmetric $K$ to the edge contrasts at those compositions is linear and injective, so the preimage of a bounded set is bounded. [lin; alg] ∎

*Check.* E7 (R = 3: $\Delta Q$ recovered exactly with non-linear levels; adding an antisymmetric $\Delta K'$ leaves $E[\Delta T\mid X]$ unchanged and moves $\tilde D$ by the predicted linear amount). 2d's single-restriction results (FD2: R1, R2, R4; FD3: bounded change and breakdown) apply unchanged to each column in 2×C (checks [P2d] Δ1). **Status: P; proof reviewed (docs/extension/reviews/PHASE2e_proof_review.md)** for (a)–(c); (d) **P; proof review pending** (corrected loading and the tree-rank proof, finding 7).

### 3.2 The sharp identified set under FD

2d FD4 gave an **outer** set. The sharp set needs Lemma G for a linear image.

**Lemma G′ (2d Lemma G for a linear image).** Let $\mathcal S$ and $m_\theta$ be as in 2d Lemma G, with $V$ a function of $W$, and $A$ a fixed linear map. In the model "$\xi\in\mathcal S(W)$ a.s. and $E[A\xi\mid V]=m_\theta(V)$ a.s.", $\theta$ is in the sharp identified set iff, for $P_V$-a.e. $v$ and all $u$,
$$\langle u,m_\theta(v)\rangle\le\int h_{\mathcal S}(A^\top u;w)\,P_{W\mid V=v}(dw).$$

*Proof.*
1. $A\mathcal S(w)$ is nonempty, compact and convex [lin-img]; it is uniformly bounded; its graph is closed: if $w_k\to w$ and $A\xi_k\to\zeta$ with $\xi_k\in\mathcal S(w_k)$, a subsequence $\xi_k\to\xi\in\mathcal S(w)$ (uniform bound; closed graph), so $\zeta=A\xi$. Its support function is $h_{\mathcal S}(A^\top u;w)$. [lin-img; Def]
2. The model is equivalent to "$\zeta\in A\mathcal S(W)$ a.s. and $E[\zeta\mid V]=m_\theta(V)$". ⇒: take $\zeta=A\xi$. ⇐: $\zeta$ is a random vector jointly distributed with $W$ (not a function of $W$). The correspondence $(w,z)\mapsto\{\xi\in\mathcal S(w):A\xi=z\}$ has nonempty compact values on the closed set $\{(w,z):z\in A\mathcal S(w)\}$ and a closed graph, so it has a Borel selector $\sigma$ [KRN]. Put $\xi=\sigma(W,\zeta)$: then $\xi\in\mathcal S(W)$ and $A\xi=\zeta$ a.s., so $E[A\xi\mid V]=E[\zeta\mid V]=m_\theta(V)$.
3. Apply 2d Lemma G to $\zeta$ and $A\mathcal S$. [1–2; 2d:L G] ∎

**Proposition E8 (sharp set under FD; R11a).** Under FD for a pair $(u,t)$, take $\xi=(\beta_u,\beta_t)$, $\mathcal S(w)=S(x,T_u)\times S(x,T_t)$, $A(\beta_u,\beta_t)=\beta_t-\beta_u$ and $m_\theta=M_{\Delta Q+\Delta K(\Delta k)}$, with $\Delta Q$ identified (E7). Here $V=X$ (with other design variables in $V$ the same argument applies conditionally on them).
(a) The sharp identified set of $\Delta k$ is
$$\Theta^{FD}_I=\Big\{\Delta k:\ \langle u,M_{\Delta H}(x)\rangle\le E\big[h_S(u;X,T_t)+h_S(-u;X,T_u)\,\big|\,V=v\big]\ \ \forall u,\ P_V\text{-a.e. }v\Big\},$$
convex; the sharp set of $\tilde D_c$ is its image, an interval.
(b) $\Theta^{FD}_I\subseteq\Theta^{FD}_O$ (2d FD4).
(c) Equality holds when $T_u$ and $T_t$ are degenerate given $V$ (no dispersion of outcomes among units with the same composition). When outcomes vary within a composition and cross the kinks of the unit bounds, inclusion was strict in 100 of 100 designs: numerical experience, not a theorem (a pointwise Jensen gap need not remove a globally feasible parameter if another composition already binds).
(d) **2×2 closed form.** With $0<x<1$, $L(t;x)=\max\{0,(t-1+x)/x\}$, $U(t;x)=\min\{1,t/x\}$ and $\Delta m_v(x;\Delta\kappa)=\Delta Q_{vv}x+(\Delta Q_{vn}+\Delta\kappa)(1-x)$:
$$\Theta^{FD}_I=\Big\{\Delta\kappa:\ \Delta m_v(x;\Delta\kappa)\in\big[E(L(T_t;x)\mid x)-E(U(T_u;x)\mid x),\ E(U(T_t;x)\mid x)-E(L(T_u;x)\mid x)\big]\ \text{for }P_X\text{-a.e. }x\Big\},$$
an intersection of intervals in $\Delta\kappa$ (the coefficient $1-x$ is positive). FD4 is the same with $L,U$ evaluated at $\tau_t(x)=E[T_t\mid x]$.
(e) **One pair; joint paths.** (a) is a one-pair theorem. Pair-by-pair constraints for several pairs that share an election are an **outer** relaxation of the joint FD set (check E8 [F]: each of two successive pairs is feasible, the three-election path is not). For FD on several pairs jointly, apply Lemma G′ once with $\xi=(\beta_t)_{t\in\mathcal T'}$, $\mathcal S(w)=\prod_tS(x,T_t)$ and $A$ the incidence matrix of the required differences: $\theta$ is in the sharp set iff $\langle u,m_\theta(v)\rangle\le E\big[\sum_th_S((A^\top u)_t;X,T_t)\mid V=v\big]$ for all $u$ and $P_V$-a.e. $v$. With finite support this is one LP with one latent level per election per support point, shared by every difference. A larger set may be used for conservative coverage (E25) if it is labelled outer.

*Proof.*
1. (a): Lemma G′ with $h_{\mathcal S}(A^\top u;w)=h_S(u;x,t_t)+h_S(-u;x,t_u)$, since $A^\top u=(-u,u)$. [G′; prod-supp] Linear inequalities in $\Delta k$ define a convex set; $\tilde D_c$ is affine in $\Delta k$ [E7(b)]. [conn]
2. (b): the constraint set $S(x,t)$ is defined by linear equalities $\beta^\top x=t$ and convex constraints, so the mean of any selection of $S(x,T)$ given $x$ lies in $S(x,\tau(x))$; hence $E[h_S(u;x,T)\mid x]\le h_S(u;x,\tau(x))$ for all $u$, for both elections. [Aumann; Def S] So every $\Delta k$ in $\Theta^{FD}_I$ satisfies FD4's pointwise condition $M_{\Delta H}(x)\in S(x,\tau_t)\oplus(-S(x,\tau_u))$. [2d:FD4]
3. (c): with $T$ degenerate given $V$ the conditional expectation of $h_S$ is $h_S$ at the conditional mean. [Def]
4. (d): $S(x,t)$ is the segment of $\{x\beta_v+(1-x)\beta_n=t\}\cap[0,1]^2$ with $\beta_v\in[L,U]$. $S(x,t_t)\oplus(-S(x,t_u))$ is a segment on the line $x\Delta_v+(1-x)\Delta_n=t_t-t_u$ with $\Delta_v\in[L(t_t)-U(t_u),U(t_t)-L(t_u)]$. For segments $[p,q]$ on parallel lines with direction $d$, $q-p=\ell d$, $\ell\ge0$, the support function is $\langle u,p\rangle+\ell\max\{0,\langle u,d\rangle\}$; its conditional expectation is the support function of $[Ep,Ep+(E\ell)d]$. $M_{\Delta H}(x)$ lies on the mean line (its $v$- and $n$-coordinates satisfy $x\Delta m_v+(1-x)\Delta m_n=E[\Delta T\mid x]$ for every $\Delta\kappa$, E7(a)), so the condition of (a) is the stated interval for $\Delta m_v$. [1; alg]
5. (e): Lemma G′ with the product set and the incidence matrix; the support function of a product is the sum. [G′; prod-supp] Outer: each pair's constraint is implied by the joint one (project out the other elections); the counterexample shows the converse fails. ∎

*Checks.* E8 [V] (discrete design, 2×2: the sharp set contains the truth, lies inside FD4, strictly in 100/100 designs); E8 [I] (degenerate case); **E8 [F]** (finding 8, (e)). **Status: P; proof reviewed (docs/extension/reviews/PHASE2e_proof_review.md)** for (a)–(d); (e) and the wording of (c) **P; proof review pending**. Computing $\Theta^{FD}_I$ from data needs conditional expectations of the kinked functions $L(T),U(T)$ given $X$ (§6, Prop. E23(c)).

### 3.3 DiD-S within FD (R11a)

**Proposition E9 (DiD-S: closed form and sharpness).** Under FD, on a prespecified set $A$ of compositions (the hull, or chosen points), impose the PD §5.1 objects on changes: the ordering of changes $O^\Delta_{rs}(x)=(\Delta Hx)_r-(\Delta Hx)_s\ge0$ and the composition-weighted spillover sign $L^\Delta_{rs}(x)=(x^\top\Delta H)_r-(x^\top\Delta H)_s\ge0$ for $x\in A$.
(a) The rows are equivalent to $\lvert g^\Delta_{rs}(x;\Delta k)\rvert\le q^\Delta_{rs}(x)$ for $x\in A$ (P-S(c)), non-empty only if $q^\Delta_{rs}\ge0$ on $A$ (a data test). For $R=2$, $g^\Delta\equiv\Delta\kappa$ (constant in $x$), so the rows are $\lvert\Delta\kappa\rvert\le q_{\min}:=\min_{x\in A}q^\Delta(x)$, which is $\min\{q^\Delta(x_L),q^\Delta(x_U)\}$ when $A$ is the hull $[x_L,x_U]$ and the minimum over the chosen points otherwise, and
$$\tilde D\in[I-s\,q_{\min},\ I+s\,q_{\min}].$$
(b) The sharp identified set of $\tilde D$ under FD + DiD-S is the image of $\Theta^{FD}_I\cap\{\text{rows}\}$.
(c) The closed form (a) is the sharp set **for the regression** (the regression of $\Delta T$ on the homogeneous quadratic does not restrict $\Delta k$; 5a's sense), always. As a set of $\Delta k$, the row set is the sharp set for the **full law** iff it lies in $\Theta^{FD}_I$. For $R=2$ ($\tilde D$ monotone in $\Delta\kappa$) the same holds for the target: the closed form is sharp for $\tilde D$ iff $[-q_{\min},q_{\min}]\subseteq\Theta^{FD}_I$. For $R\ge3$ that inclusion is sufficient but not necessary for the target's sets to coincide (a projection can coincide while the sets of $\Delta k$ differ). When $(X,T_u,T_t)$ has finite support (e.g. the empirical law), (b) is one LP, with selection variables per support point.

*Proof.*
1. (a): P-S(b) applied to $\Delta H$ gives $O^\Delta=q^\Delta+g^\Delta$ and $L^\Delta=q^\Delta-g^\Delta$; (c) of P-S gives the equivalence. [PD:P-S] For $R=2$, $K=\kappa\begin{psmallmatrix}0&1\\-1&0\end{psmallmatrix}$ gives $(Kx)_v-(Kx)_n=\kappa(1-x)+\kappa x=\kappa$. $q^\Delta$ is affine in $x$, so its minimum over an interval is at an end. $\tilde D=I+s\Delta\kappa$. [alg; E7(c)]
2. (b): the rows restrict the parameter only. [param; E8(a)]
3. (c): the regression's identified set for $\Delta k$ is everything [E7(a)], so with the rows it is the row set. Under the full law it is (b), which equals the row set iff the row set lies in $\Theta^{FD}_I$; for $R=2$ the target is a monotone function of $\Delta\kappa$, so the sets of $\tilde D$ coincide iff the intervals of $\Delta\kappa$ do. With finite support the conditions of E8(a) are finitely many linear inequalities after Minkowski selection variables. [2; E8] ∎

*Checks.* E9 [V] (a): rows on a fine grid of the hull = closed form; (b)–(c): the truth lies in the sharp set; the closed form is sharp in most designs and strictly wider in a constructed one ($\Delta Q=(.03,0,-.03)$ and every unit at $x=.5$ starting at 0: sharp set $\{-.03\}$ against $[-.03,.03]$). **Status: P; proof reviewed (docs/extension/reviews/PHASE2e_proof_review.md).** This settles PD §8's R11 item "DiD-S sharp within FD": sharp for the regression, sharp for the full law under the stated condition, and computable exactly otherwise.

### 3.4 Contrasts on changes in the model layer

**Proposition E10 (LCE-layer contrast on changes).** Under FD, for prespecified compositions $x_L,x_H$ with $x_H-x_L=\lambda(e_r-e_s)$, $\lambda>0$, and $\Delta m(x)=\Delta Hx$, $\Delta\tau(x)=x^\top\Delta Hx$:
$$\Delta\tau(x_H)-\Delta\tau(x_L)=\underbrace{\lambda\,O^\Delta_{rs}(\bar x)}_{\text{mix}}+\underbrace{\lambda\,L^\Delta_{rs}(\bar x)}_{\text{rate}},\qquad\bar x=(x_L+x_H)/2.$$
So the two contrast rows at a pair of compositions are the DiD-S rows at its midpoint; at every pair of the hull they are DiD-S on the hull. They are linear rows in $\Delta k$; Prop. E9(b)–(c) applies.

*Proof.* $\Delta\tau(x_H)-\Delta\tau(x_L)=(x_H-x_L)^\top\frac{\Delta m(x_H)+\Delta m(x_L)}2+\bar x^\top(\Delta m(x_H)-\Delta m(x_L))$ (Kitagawa). By linearity of $\Delta m$ the first term is $(x_H-x_L)^\top\Delta H\bar x=\lambda O^\Delta_{rs}(\bar x)$ and the second is $\bar x^\top\Delta H(x_H-x_L)=\lambda L^\Delta_{rs}(\bar x)$. [alg; Def] ∎

## 4. How the rungs combine

### 4.1 The rule

Within a layer, rows combine in one LP (L). Across layers (count rows on the realised tables; model rows on $k$) they never share an LP; their answers for the **actual** target are intersected (∩), per 6a R27. The causal layer (§5) sits on top (↑).

**Lemma E12 (residual allowance for multi-election targets).** Let $\varphi(n)=\varphi_0+\sum_{i,r,c,t}v_{irct}n_{irct}$ with coefficients that are functions of the design, and $E_\varphi=\varphi(n^\circ)-\tilde\varphi$. Assume independence **across units** given the design, with any dependence **across elections and groups within a unit**, and a mean condition: either (levels rungs) P3-S1a for the stacked unit vectors, $E[\beta_{it}\mid\text{design}]=m_t(V_i)$ for every $t$; or (FD) only $E[\Delta\beta_i\mid\text{design}]=M_{\Delta H}(X_i)$. Under FD, (i) $\tilde\varphi$ is defined only for **change targets**, whose coefficients at $u$ and $t$ are opposite within each $(i,r,c)$ ($v_{irct}=-v_{ircu}$, others zero), and (ii) the DiD and every quantity of §5 built from $D_s$ are such targets. Then 6a Lemma 4.1 (a)–(b) hold, (a) under its Lindeberg condition $\max_i\rho_i^2/\sum_i\rho_i^2\to0$, with
$$\rho_i:=\sum_ra_{ir}\sum_t\big(\max_cv_{irct}-\min_cv_{irct}\big).$$
For the DiD $D_c(r,s;u,t)$, $\rho_i=2(w_{ir}+w_{is})$ with $w_{ir}=a_{ir}/A_r$, so $S_D=\big(\sum_i(w_{ir}+w_{is})^2\big)^{1/2}$, twice the single-election gap allowance; the bound is attained (opposite $\pm1$ changes of the two groups). The Hoeffding radius is $t_E=(\tfrac12\log(2/\alpha_E)\sum_i\rho_i^2)^{1/2}$.

*Proof.* 6a Lemma 4.1 steps 1–5 with $Z_i=\sum_ra_{ir}\sum_t\sum_cv_{irct}\beta_{irct}$; step 1 needs $E[Z_i\mid V_i]=\tilde Z_i$, which is the mean condition (for a change target under FD, $Z_i=\sum_ra_{ir}\sum_cv_{irct}\Delta\beta_{irc}$ and $E[\Delta\beta_i\mid V_i]=M_{\Delta H}(X_i)$); for each $(r,t)$, $\beta_{ir\cdot t}$ lies in the simplex, so $\sum_cv_{irct}\beta_{irct}\in[\min_cv_{irct},\max_cv_{irct}]$; summing over $t$ and $r$, $Z_i$ lies in an interval of length $\rho_i$, whatever the dependence across elections and groups within the unit. The $Z_i$ are independent across units. [6a:L4.1; P3-S1a; simplex] For the DiD the four non-zero coefficients per unit are $\pm1/A_r$, $\pm1/A_s$. ∎

*Check.* E12 (random dependent laws: ratio to the bound at most 0.40; the extreme law attains 1). **Status: P; proof reviewed (docs/extension/reviews/PHASE2e_proof_review.md).** The normal bound in (a) uses the variance-subsequence argument of 6a Lemma 4.1 and P3; a scale based on ranges alone need not give a CLT standardised by the actual variance. Opposite coefficients on a given pair suffice for FD; for a linear combination of several modelled changes define the estimand on their span and combine coefficients period by period. Nonlinear functions, such as the largest absolute pre-trend, need a joint region for their linear constituents (E25). The Bhatia–Davis version proposed in 2d §11 and 1b B5 is **not** covered (6a Lemma 4.1: Popoviciu only for multi-cell targets; P3.5(c1) is for single cells); see §11.

**Theorem E13 (cross-layer rule on the T-election product).** Let $\mathcal C_\varphi$ be the count-layer set for an actual target $\varphi$ on the T-election tables (Lemma E1: margins and any count rows of §2), and $\mathrm{CI}_\varphi$ an actual-target model interval at level $1-\alpha$ built from any model-layer rung of §3 (FD with its rows, DiD-S, per-period LCE with model rows on changes), using Lemma E12's allowance. Then 6a R27 holds verbatim: the union bounds $(*)$; coverage at least the model interval's with **identity rows only** (margins, published totals, audited cells, in any election); with **belief rows** (realised signs, CR or contrasts on changes, orderings, boxes) coverage at least $1-\alpha-P(n^\circ\notin F)$, and only $P(\text{reject while the rows hold})\le\alpha$; the intersection is not in general the smallest valid set.

*Proof.* 6a R27's proof uses only (1) that on $\{n^\circ\in F\}$ the realised target lies in $\mathcal C_\varphi$ (R19(a) item 2), (2) an actual-target interval, and (3) the union bound. (1) holds by Lemma E1; (2) by P3.5 with Lemma E12's allowance; (3) is unchanged. [E1; E12; 6a:R27] ∎

*Check.* E13 (FD + R1, 400 units, 300 replications: coverage of the intersection equals the model interval's in every replication; disjointness rate 0.000 ≤ α). **Status: P; proof reviewed (docs/extension/reviews/PHASE2e_proof_review.md)**, with the model interval's status inherited (6a §4.3; §6 below). The model interval must be for the actual target: a plug-in model set is not (6a check X3).

This resolves PD §7's open items "FD4 ∩ Δ4 (mixes mean-level and realised quantities)" and "LCE-levels ∩ sign-on-changes": the first is ∩ by Theorem E13; the second is L within the model layer (E11) when the sign is a model sign, and ∩ when it is a realised sign.

## 5. The causal layer

### 5.1 Potential outcomes, the estimand and the identity

* A **treated group** $r^*$ (a row; for example veterans) receives a treatment between elections 0 and 1 (service). A **comparison group** $s^*$ is another row, or all other rows ("rest").
* [PO] $Y_{jt}(0)$ is person $j$'s outcome at election $t$ had **nobody** been treated (the global no-treatment counterfactual). $B^{(0)}_{rct}=\frac1{A_r}\sum_{j\in r}\mathbf 1\{Y_{jt}(0)=c\}$.
* **(NA) No anticipation:** $Y_{jt}=Y_{jt}(0)$ for every person and every $t\le0$.
* **Estimand:** $\mathrm{ATT}_t:=B_{r^*ct}-B^{(0)}_{r^*ct}$ for $t\ge1$: the total effect of the treatment programme on the treated group's rate (it includes any effect on treated people of others' treatment). Under interference write $Y_{jt}(\mathbf z^{obs})$ for the outcome under the observed assignment: the estimand is the total effect of the programme assignment on its treated group.
* **Spillover onto the comparison group:** $S_t:=B_{s^*ct}-B^{(0)}_{s^*ct}$ ($S_t=0$ for $t\le0$ by NA). $S_t=0$ means zero **net** effect on the comparison group's rate; individual spillovers could cancel.
* **Counterfactual trend gap:** $b_t:=(B^{(0)}_{r^*ct}-B^{(0)}_{r^*c0})-(B^{(0)}_{s^*ct}-B^{(0)}_{s^*c0})$, so $b_0=0$.
* **Parallel-trends imputation:** $\theta_t:=B^{(0)}_{r^*ct}$ and $\theta^{PT}_t(n):=B_{r^*c0}+B_{s^*ct}-B_{s^*c0}$.

**Lemma E14 (the identity).** Under (FP) and NA, with $D_t=D_c(r^*,s^*;0,t)$:
(a) $\mathrm{ATT}_t=D_t-b_t+S_t$ for $t\ge1$;
(b) $D_t=b_t$ for $t<0$: the pre-period DiDs **are** the counterfactual trend gaps, but they are set-valued, as functions of the latent tables;
(c) $\theta_t=\theta^{PT}_t+b_t-S_t$. The only logical constraints are $\theta_t\in[0,1]$ and $B_{s^*ct}-S_t\in[0,1]$.

*Proof.* NA gives $B_{r^*c0}=B^{(0)}_{r^*c0}$ and $B_{s^*c0}=B^{(0)}_{s^*c0}$. Then $D_t=(B_{r^*ct}-B^{(0)}_{r^*c0})-(B_{s^*ct}-B^{(0)}_{s^*c0})=\mathrm{ATT}_t+(B^{(0)}_{r^*ct}-B^{(0)}_{r^*c0})-(S_t+B^{(0)}_{s^*ct}-B^{(0)}_{s^*c0})=\mathrm{ATT}_t+b_t-S_t$. For $t<0$ also $B_{r^*ct}=B^{(0)}_{r^*ct}$ and $S_t=0$. (c) rearranges (a) with $\mathrm{ATT}_t=B_{r^*ct}-\theta_t$. The counterfactual rates are rates, and nothing else links them to the data under (FP). [PO; NA; alg] ∎

*Check.* E14. **Status: P; proof reviewed (docs/extension/reviews/PHASE2e_proof_review.md).**

### 5.2 The labelling rule

**Definition 5.1 (causal label).** A statement about $\mathrm{ATT}_t$ may be labelled causal only if it states:
0. the population for which the ATT is defined: the fixed population (FP), or the stayers with fixed group membership when (FP) fails (§8, G1–G4, G9);
1. the treated group $r^*$, and the comparison group $s^*$ when the trend assumption uses one (MTR and ND alone do not);
2. a trend assumption: a dial $\lvert b_t\rvert\le M$; relative magnitudes $\bar M$ with the pre-periods used; smoothness $M$; or MTR/ND/PS;
3. a spillover assumption $\lvert S_t\rvert\le\Lambda$, with $\Lambda=0$ stated explicitly if assumed, whenever the trend assumption uses a comparison group (PT, the dial, RM, SD, PS); MTR and ND alone need none;
4. no anticipation;
5. the descriptive information it rests on (the count rows and/or model rung).

Anything else is descriptive and is printed separately. Definition 5.1 is a reporting convention, not a theorem. Item 2 includes the choice between electorate-wide and within-precinct parallel trends (§5.8); there is no default.

**Proposition E15 (without a trend assumption nothing causal follows).** Under (FP), NA and any count information $F$, with no restriction on $(\theta_t,S_t)$ beyond the logical ones, the set of $\mathrm{ATT}_t$ is
$$\{B_{r^*ct}(n)-\theta:\ n\in F,\ \theta\in[0,1]\}=[B^L_{r^*ct}-1,\ B^U_{r^*ct}]$$
(ends over $F$, nonempty). It always contains 0 and does not depend on $s^*$; pre-period tables enter only through count rows that link elections, which can move $B^L,B^U$. Untreated trends add no restriction, so the **sign** of the effect is not identified without a trend assumption, though the observed post rate can still limit the effect substantially. Without a stated comparison group, $D_t$, the dial, RM, SD and PS are undefined; MTR and ND alone need none (they give $\mathrm{ATT}_t\in[0,B_{r^*ct}-B_{r^*c0}]$, E21 without PS).

*Proof.* $\theta$ is free in $[0,1]$ [E14(c)] and $S_t$ does not enter $\mathrm{ATT}_t=B_{r^*ct}-\theta_t$ once $\theta_t$ is free. For each $n\in F$ the set is $[B_{r^*ct}(n)-1,B_{r^*ct}(n)]$, which contains 0; a union of intervals that all contain 0 is the interval from the smallest lower end to the largest upper end, whether or not $F$ is connected. [E14(c); alg] ∎

### 5.3 The joint causal LP

**Theorem E16 (validity, sharpness, refutability; R11b).** Let the causal assumption be a finite union $\Gamma=\bigcup_k\Gamma_k$ of polyhedra in $(n,(\theta_t,S_t)_{t\ge1})$ (all forms of §§5.4–5.7 are of this kind), with $\lvert S_t\rvert\le\Lambda$. The statement is for one post-period $t$ or for the vector of post-periods (the rate limits below then hold for each $t$, and the target is any one $\mathrm{ATT}_t$ or a linear combination). For one $t$, put
$$\mathcal A=\big\{B_{r^*ct}(n)-\theta:\ n\in F,\ (n,\theta,S)\in\Gamma,\ \theta\in[0,1],\ B_{s^*ct}(n)-S\in[0,1],\ \lvert S\rvert\le\Lambda\big\}.$$
(a) **Valid:** if (FP), NA, the count information ($n^\circ\in F$) and the causal assumption hold, $\mathrm{ATT}_t\in\mathcal A$.
(b) **Sharp** for continuous tables: every value in $\mathcal A$ is the ATT of some realised table and potential-outcome configuration consistent with all the stated information; with MTR in $\Gamma$, MTR holds as an inequality between masses in every unit. **Finite persons.** A whole-person witness needs an integer $n$ with $A_{r^*}\theta_t\in\mathbb Z$ **and** $(B_{s^*ct}(n)-S_t)A_{s^*}\in\mathbb Z$ at every post-period (check E16 [F]: one treated and one comparison person, both voting yes, $\theta=0$, $S=1/2$); then a greedy allocation in each group gives integer counterfactual counts, and with MTR in $\Gamma$ the configuration satisfies MTR person by person. The construction is for the indicator of one designated outcome $c$; with several categories it must also respect adding-up across categories.
(c) $\mathcal A$ is a union of at most $K\cdot K_F$ intervals, each the projection of an LP, where $K_F$ is the number of branches of $F$ (CR rows make $F$ a union); one interval when $\Gamma$ and $F$ are single polyhedra.
(d) **Refutable:** $\mathcal A=\emptyset$ refutes the conjunction of (FP), NA, the count rows and the causal assumption. For one post-period, parallel trends with no spillover ($M=0$, $\Lambda=0$) is refuted iff $\theta^{PT}_t(n)\notin[0,1]$ for every $n\in F$. For several post-periods (absent further causal rows) it is feasible iff **one** $n\in F$ has $\theta^{PT}_t(n)\in[0,1]$ for **every** post-period; feasibility at each post-period separately is not enough (check E16 [F], finding 9).

*Proof.*
1. (a): the true $(n^\circ,\theta_t,S_t)$ satisfies every constraint: $n^\circ\in F$; $\Gamma$ by assumption; the rate limits because $\theta_t$ and $B^{(0)}_{s^*ct}$ are rates. [E14; Def]
2. (b): take a feasible $(n,(\theta_t,S_t)_t)$. Use $n$ as the realised table. For the treated group at each post-period $t$, choose unit masses $z_i\in[0,a_{ir^*}]$ with $\sum_iz_i=\theta_tA_{r^*}$ (possible as $\theta_t\in[0,1]$). Under MTR choose $z_i\in[0,n_{ir^*ct}]$ with $\sum_iz_i=\theta_tA_{r^*}$, possible as $\theta_tA_{r^*}\le\sum_in_{ir^*ct}$ (if $B_{r^*ct}(n)=0$ then $\theta_t=0$ and $z\equiv0$); with integer $n$ and $\theta_tA_{r^*}\in\mathbb Z$ the $z_i$ can be chosen integer (fill units greedily). Give $Y_{jt}(0)=c$ to $z_i$ of the $n_{ir^*ct}$ people of $(i,r^*)$ observed with outcome $c$ (integer case), so $\mathbf 1\{Y_{jt}(1)=c\}\ge\mathbf 1\{Y_{jt}(0)=c\}$ for each of them; in the continuous case the unit masses satisfy $z_i\le n_{ir^*ct}$. For the comparison group choose unit counterfactual masses in $[0,a_{is^*}]$ summing to $(B_{s^*ct}(n)-S_t)A_{s^*}$, possible as $B_{s^*ct}(n)-S_t\in[0,1]$, and integer (greedily) when $(B_{s^*ct}(n)-S_t)A_{s^*}\in\mathbb Z$. At $t\le0$ set $Y(0)=Y$ (NA). The forms of §§5.4–5.7 constrain only $(\theta_t,S_t)_t$ and functions of $n$, all matched; different post-periods involve different $(\theta_t,S_t)$, so the construction is per $t$. [Def; alg]
3. (c): each $\Gamma_k$ with each branch of $F$ and the other constraints is a polyhedron in $(n,\theta,S)$; the ATT is linear; its image is an interval [conn]; take the union over the $K\cdot K_F$ pairs. [Def]
4. (d): (a). With $M=\Lambda=0$, $\theta_t=\theta^{PT}_t(n)$ at the same $n$ for every post-period [E14(c)], each of which must lie in $[0,1]$; conversely such an $n$ with $\theta_t:=\theta^{PT}_t(n)$ is feasible. [E14] ∎

*Checks.* E16, E18, E19, E21 (LPs); **E16 [F]** (findings 4 and 9). **Status: P; proof review pending (independent review; earlier version proof reviewed).** (finite-person condition and the joint-post quantifier).

### 5.4 Form 1: the trend dial

**Corollary E17 (trend dial).** With $\Gamma=\{\lvert b_t\rvert\le M\}$ ($b_t=D_t(n)+S-(B_{r^*ct}(n)-\theta)$, linear):
(a) $\mathcal A\subseteq\mathcal D_t\oplus[-(M+\Lambda),\,M+\Lambda]$, where $\mathcal D_t$ is the descriptive set of $D_t$;
(b) **exact criterion:** the upper end of $\mathcal A$ equals $\max_FD_t+M+\Lambda$ **iff** some $n\in\arg\max_FD_t$ has $\theta^{PT}_t(n)\in[M+\Lambda,\,1+M+\Lambda]$ and $B_{s^*ct}(n)\ge\Lambda$; the lower end equals $\min_FD_t-M-\Lambda$ iff some $n\in\arg\min_FD_t$ has $\theta^{PT}_t(n)\in[-(M+\Lambda),\,1-M-\Lambda]$ and $B_{s^*ct}(n)\le1-\Lambda$. Under margins only (any $R$; a named comparison row or the rest) a maximiser of $D_t$ minimises $\theta^{PT}_t$ and a minimiser maximises it, so when the two inner conditions hold (at $n^+$ and at $n^-$) the two outer ones follow;
(c) for the conclusion "$\mathrm{ATT}_t>0$" on the Minkowski form, the breakdown value is $M^*=\min\mathcal D_t-\Lambda$ (when positive). For the **sharp** conclusion the breakdown value is $\min\{M:\ (n,\theta,S)\text{ jointly feasible},\ \mathrm{ATT}_t\le0\}$, one LP with $M$ a variable (infinity if no such witness exists); refutation ($\mathcal A=\emptyset$) is reported separately. It is at least $M^*$.

*Proof.* (a): $\mathrm{ATT}=D-b+S$ [E14(a)]. (b): $\mathrm{ATT}\le D_t(n)+M+\Lambda\le\max_FD_t+M+\Lambda$, with equality only at $n\in\arg\max D_t$, $b=-M$, $S=\Lambda$; there $\theta=\theta^{PT}_t(n)-M-\Lambda$ [E14(c)], which lies in $[0,1]$ iff $\theta^{PT}_t(n)\in[M+\Lambda,1+M+\Lambda]$, and the comparison limit is $B_{s^*ct}(n)-\Lambda\ge0$ (the upper comparison limit $B_{s^*ct}-\Lambda\le1$ holds as $\Lambda\ge0$). Symmetric at the lower end. Margins only: $D_t=B_{r^*ct}-\theta^{PT}_t$ with $\theta^{PT}_t=B_{r^*c0}+B_{s^*ct}-B_{s^*c0}$; maximising $D_t$ puts $B_{r^*ct}$ at its maximum and $B_{s^*ct}$, $B_{r^*c0}$ at their minima and $B_{s^*c0}$ at its maximum, all jointly attainable (6a Lemma 2.1(b); for the rest, $B_{\neg r^*}$ decreasing in $Y_{r^*}$), which also minimises $\theta^{PT}_t$; symmetrically for the minimum. Then $\theta^{PT}_t(n^+)\le\theta^{PT}_t(n^-)\le1-M-\Lambda\le1+M+\Lambda$ and $\theta^{PT}_t(n^-)\ge\theta^{PT}_t(n^+)\ge M+\Lambda\ge-(M+\Lambda)$. (c): the lower end of the Minkowski form is $\min\mathcal D_t-M-\Lambda$; the sharp set is contained in it [(a)], so it stays positive at least up to $M^*$; $|b|\le M$ is linear in $(b,M)$. [E14; E16; 6a:L2.1] ∎

*Checks.* E16/E17 [V] (the LP lies in the Minkowski set; equal in 40 cases, rate limits bind in 80); **E17 [F]** (review issue 1: one 2×2 unit, 100 of 200 voting yes at both elections, one coupling row $3y_0-2y_1=140$: the earlier sufficient condition holds but the sharp upper end under parallel trends is $-0.800<\max D=-0.400$; the exact criterion predicts it); E17 [V] (margins only: the criterion's outer conditions are implied); **E17 [I]** NS's arithmetic: $\mathcal D=[.05,.25]$, $M=.10$ gives $[-.05,.35]$, $M=.02$ gives $[.03,.27]$, $M^*=.05$; E17 [V] (finding 9: the sharp breakdown LP). **Status: P; proof reviewed (docs/extension/reviews/PHASE2e_proof_review.md)** for (a)–(b); the sharp breakdown in (c) **P; proof review pending**.

### 5.5 Form 2: bounds relative to pre-period trends (R11b′)

With $L\ge1$ pre-periods, write the violations as $\delta_t:=b_t$ ($\delta_0=0$; $\delta_t=D_t(n)$ for $t<0$ by E14(b)).

**Definition 5.2 (Rambachan–Roth relative magnitudes, RM($\bar M$)).** For every post-period $t\ge1$,
$$\lvert\delta_t-\delta_{t-1}\rvert\le\bar M\,A(n),\qquad A(n):=\max_{-L<s\le0}\lvert\delta_s-\delta_{s-1}\rvert=\max_{-L<s\le0}\lvert g_s(n)-g_{s-1}(n)\rvert,$$
the largest consecutive pre-period DiD in absolute value. For one post-period this is $\lvert b_1\rvert\le\bar M A(n)$. NS §3.2 writes $\max_{t\le0}\lvert D_t\rvert$ (levels relative to the base); the two coincide for $L=1$ and differ for $L\ge2$ (check E19 [I]). In Rambachan–Roth, $\delta_t$ is the whole bias of the event-study coefficient; by E14(a) that is $b_t-S_t$. Here $\delta_t:=b_t$ **excludes** the spillover deliberately: pre-periods carry no information on $S_t$ (E22), which gets its own dial $\Lambda$.

**Definition 5.3 (smoothness, SD($M$)).** $\lvert(\delta_{t+1}-\delta_t)-(\delta_t-\delta_{t-1})\rvert\le M$ for every $t$ with $t\pm1\in\mathcal T$ (pre-periods included, which makes SD testable).

**Proposition E18 (the joint form).**
(a) Under RM the ATT set (for one post-period, or the vector of post-periods, using Theorem E16 in its vector form) is Theorem E16's $\mathcal A$ with
$$\Gamma_{RM}=\bigcup_{-L<s\le0}\ \bigcup_{\sigma=\pm1}\Big\{\lvert\delta_t-\delta_{t-1}\rvert\le\bar M\,\sigma\big(g_s(n)-g_{s-1}(n)\big)\ \ \forall t\ge1\Big\},$$
a union of $2L$ polyhedra. With a count set of $K_F$ branches, the scalar ATT set is a union of up to $2LK_F$ LP projections under RM and $K_F$ under SD; the vector projection is a union of polytopes. **The union can have holes even when $F$ is one polytope**: report the branch intervals, merging only overlaps, never their envelope (check E18 [F], finding 12: one precinct, three equal groups with early, base and post rates $(.75-x/2,.25+x/2,.50)$, $(.75,.25,.50)$, $(.50+2x,.60,.40-2x)$, $-.2\le x\le.2$, one polytope of tables; RM(1) gives $[-.90,-.70]\cup[-.30,0]$, and the envelope would wrongly include $-.50$).
(b) **Endpoint-wise outer sets.** For the **first** post-period with $\Lambda=0$, the set $\mathcal D_1(F)\oplus[-\bar M\sup_FA,\ \bar M\sup_FA]$ contains the joint set. At horizon $h\ge1$, violations accumulate: $\lvert b_h\rvert\le h\bar MA(n)$, so the marginal outer set is $\mathcal D_h(F)\oplus[-h\bar M\sup_FA-\Lambda,\ h\bar M\sup_FA+\Lambda]$. For joint statements (contrasts across horizons, simultaneous inference) keep the path constraints of (a); a product of marginal sets is not the joint set. Only (a) is sharp (E16(b)).

*Proof.* (a): $x\le\bar M\max_ky_k$ iff $x\le\bar My_k$ for some $k$; the maximum is the same for every post-period, so one $k=(s,\sigma)$ serves all $t$. Each branch is linear in $(n,\theta,S)$ ($\delta_t$ for $t\ge1$ is linear by E14, and $\lvert\cdot\rvert\le$ linear is two linear rows). [alg; E14] (b): $b_h=\sum_{t=1}^h(\delta_t-\delta_{t-1})$ with $b_0=0$, each term at most $\bar MA(n)\le\bar M\sup_FA$ in absolute value, so $\lvert b_h\rvert\le h\bar M\sup_FA$; $\mathrm{ATT}_h=D_h-b_h+S_h$ with $D_h(n)\in\mathcal D_h(F)$ and $\lvert S_h\rvert\le\Lambda$ [E14(a)]. Check E18 [F] (finding 1): at horizon 2, $D_2=0$, $A=.15$ and $\mathrm{ATT}_2=-.30$, outside $\pm A$ and inside $\pm2A$. [Def; alg] ∎

### 5.9 Baseline, post-election and change LCE in one calculation (E30)

## 9. What can be said, under which assumptions (plain language)

*No formulas. The question is the owner's: "EI DiD with a causal reading: what can we say, and with what assumptions?"*

### 9.1 The two questions

* **The descriptive question.** Among the same people, did one group's support change more than another's between two elections? This is the **difference-in-differences (DiD)**. We never see how each group voted, only each place's group shares and totals, so even this is a range.
* **The causal question.** Did the treatment (say, war service) change the treated group's support? That compares what the treated group did with what it **would have done** without treatment, which nobody observes. Every causal number therefore rests on an assumption about that unseen path, on top of the descriptive range.

The two must be reported separately. A causal number needs four things stated: **who is compared with whom**; **how far the two groups' untreated paths could have differed** (the trend assumption); **whether treatment could have affected the comparison group** (spillovers); and that **treatment did not affect votes before it began** (no anticipation; voters may change freely between earlier elections). A fifth choice matters for the comparison: **whose trend stands in for the veterans' untreated trend**, the non-veterans of the whole electorate or the non-veterans in each veteran's own precinct (§9.4).

### 9.2 The ladder, with a worked example

### 9.3 What the theory says, in ten sentences

1. **The arithmetic range of the DiD is the sum of the elections' ranges, and it is the best possible without further beliefs** (Prop. E3). With more elections, the event-study DiDs are linked through the shared base election; treating them as separate boxes overstates what is possible.
2. **Beliefs about the actual voters' changes (signs, contextual reinforcement, comparisons between kinds of places) narrow the DiD exactly**, with no model and no sampling error (Props E5, E6). Contextual reinforcement on changes is never contradicted by the counts in the continuous problem and signs the DiD by Goodman's regression on changes; with whole-ballot counts it can be contradicted (Prop. E26(c)).
3. **Straight-line models of the changes (FD) allow any persistent local culture**, and give an exact range (Prop. E8) that is usually narrower than the earlier outer range; one extra rule (R1, R2 or R4) gives a single number, and the "ordering plus spillover-sign" pair (DiD-S) gives a closed-form range (Prop. E9).
4. **A model range and an arithmetic range combine by overlap** for the actual DiD, with the model's confidence level; their disagreement is a test of the model and the beliefs together (Theorem E13).
5. **Without a trend assumption the data say nothing about the effect of treatment** (Prop. E15).
6. **Relative-magnitude bounds help when the pre-trends they allow are small compared with the post-war signal** (Prop. E19). On the counts alone the allowance is at least the relative magnitude times half the pre-war election's arithmetic width: large with mixed precincts (as in §9.2, no information), small with nearly pure ones, where RM can sign the effect with no model at all (two precincts of 99 and 1 veterans: effect between 12 and 28 points). Beliefs about the pre-war changes or known pre-war counts can only narrow the set; a model-based pre-trend needs a joint confidence region. Later post-war elections accumulate allowed violations, so their allowance grows with the horizon (Prop. E18(b)). Under smoothness, linear extrapolation of a set-valued pre-trend counts the base election's width twice (Prop. E20).
7. **Spillovers onto the comparison group cannot be learned from pre-periods**, because they did not exist then; they need their own allowance (Prop. E22).
8. **People entering, leaving, aging in, censuses that disagree, and boundaries that move are not solved here.** Each is listed in the gap register (§8) with what still holds, what would close it, and where a range with stated confidence would enter.
9. **Whose trend is the comparison is a choice, with no default** (§5.8). Electorate-wide parallel trends compares veterans with all non-veterans; within-precinct parallel trends in expectation compares each veteran with the non-veterans of their own precinct, which lets every place have its own trend but leans on few comparison voters where veterans are concentrated (report that share; places with none are bounded without assumptions). On identical returns the two can give opposite signs (§9.4).
10. **With whole ballots, the finite-electorate effect can be much narrower than the continuous range** (Remark 7.1): there is no rule that the two differ by at most one vote; when individual counts matter, solve the whole-ballot problem.

### 9.4 Which comparison? Electorate-wide or within each precinct

Both choices target the same thing: the expected effect of service on the veterans who actually served. They differ in whose change stands in for the veterans' untreated change.

| | Electorate-wide parallel trends | Within-precinct parallel trends (in expectation) |
|---|---|---|
| The assumption | Without service, veterans' support would have moved like all non-veterans' | Without service, veterans' support would have moved, on average, like that of the non-veterans **in their own precinct** |
| Whose trend is used | Every non-veteran equally | Each precinct's non-veterans, weighted by **that precinct's share of the veterans** |
| What it allows | One common untreated trend for the two groups | A different untreated trend in every precinct |
| What it leans on | Places where many non-veterans live | Places where many veterans live, even if they have few non-veterans (report that share; places with none are bounded with no assumption) |
| Realised version (the actual voters) | §§5.3–5.7 | The descriptive target $D_W$, reported separately; it is not a confidence interval for the expected effect (Prop. E29) |

**On identical returns the two can disagree.** In the review's experiment with five precincts, one of which recorded almost no yes votes in both elections, the same returns and the same straight-line model of changes give an effect of +10 to +12 points within precincts and −4 to −2 points electorate-wide (Prop. E28). The returns cannot say which comparison is credible; that is the researcher's argument. In the four-precinct example of §9.2, precinct 4's ten non-veterans carry 47.5% of the within-precinct comparison and 2.5% of the electorate-wide one.

**Straight lines in both elections help.** If each group's expected support is a straight line in the veteran share at the base and its change is too, the post-election line follows; any two of the three give the same answer (Prop. E30). In the review's three-precinct check the effect is −49 to +7 points with straight-line changes only, and +2.7 to +7.3 points once the baseline is straight as well; a baseline bend of one sixth of a point is enough to lose the sign.
