changed here). First recorded against tag `v0.3.1` (commit `c02954e`); the paper is now pinned to commit
`44db8f1` (branch `claude/wizardly-volta-lbh4bm`), which resolves items 1–4 in the sources. Item 5 is a
notation note and stays. None affects a proved result.
