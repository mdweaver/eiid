# Issues found in the sources while writing the paper

Recorded, not fixed (the sources, scripts, package and `docs/report/` were not changed). Checked
against tag `v0.3.1` (commit `c02954e`). None affects a proved result.

| # | Where | Issue | Kind | What the paper does |
|---|---|---|---|---|
| 1 | `PHASE3_inference.md` §8.1 table, column "Projection, B" | Two cells still show the earlier version of the projection interval for B, with the Bhatia–Davis bound taken from a CLR interval: design E 0.249 and design B demobilisation 0.377. The rerun table in §8 of the same document gives the P3.5(c1) version (`proj_B`) as 0.251 and 0.378 (and lists 0.249/0.377 as `proj_B_clrbd`, "not covered"). The other cells of the column agree with the rerun. | stale table cells | Table 4 uses the rerun (P3.5(c1)) values 0.251 and 0.378. |
